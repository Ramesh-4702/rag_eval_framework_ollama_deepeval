# rag_eval_framework_ollama_deepeval
**Built an offline RAG pipeline** using **LangChain, ChromaDB, and Ollama (Llama 3.2)**. Developed an automated testing suite with **Pytest and DeepEval** for Faithfulness &amp;amp; Relevancy metrics. Engineered a custom **Qwen 2.5 judge wrapper** with constrained JSON mode to ensure deterministic LLM evaluation.
